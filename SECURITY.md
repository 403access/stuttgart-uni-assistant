# Security policy

University Assistant handles university credentials and student data. Please report security issues
privately rather than in a public issue.

- **Contact:** [uni-assistant@olimo.me](mailto:uni-assistant@olimo.me)
- **Languages:** German, English
- **Scope:** the Expo app, the assistant server in `server/`, the static site in `site/`, and the
  documentation build in `docs-site/`
- **Please include:** affected version or commit, platform, a short reproduction, and the impact you
  expect. Do not include real C@MPUS, UniMail, or other people's credentials.
- **Do not:** test against accounts or data that are not yours, run denial-of-service tests, or
  publish details before a fix is available.

We aim to acknowledge reports within five working days. There is no bug bounty. Good-faith reports
that respect this policy will be handled transparently, and we will credit you if you want.
