Dashboard nicht konfiguriert

Die Verwaltung bleibt absichtlich gesperrt, solange kein Operator-Token gesetzt ist.

  1. Trage einen langen Zufallswert in .env ein:
DASHBOARD_TOKEN=ein-langes-zufaelliges-token

Danach npm run assistant neu starten und diese Seite neu laden. Jede /v1/admin/*-Route antwortet ohne Token mit 503.
