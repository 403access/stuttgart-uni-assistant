## The fastest routes while the Prototype Fund gate is closed

1. **Deutschlandstipendium** — you are an enrolled B.Sc. student, so the €300/month scholarship is the immediate fit. The University of Stuttgart 2027/28 call is expected around **December 2026**. See [opportunities.md](../opportunities.md#deutschlandstipendium-university-of-stuttgart).
2. **Employer release** — get the letter signed, then submit to the Prototype Fund before 30 November 2026.
3. **Studienstiftung** — self-application with the ability test; the registration window has historically been in February (12 February 2026 for that cycle, so expect the same window in 2027). Check the current dates.

## What only you can do

These drafts stop short of submission on purpose. Only the applicant can:

1. **Confirm or create the legal status** — a part-time release, a freelance registration, or a GbR.
2. **Make the repository public.**
3. **Create the account and submit** — Prototype Fund at [bewerben.prototypefund.de](https://bewerben.prototypefund.de/), NLnet at [nlnet.nl/propose](https://nlnet.nl/propose/).
4. **Answer the disclosure question truthfully.** Both ask whether generative AI was used; NLnet wants the prompts and outputs logged.

Everything a tool can prepare — the framing, the scope, the budget logic, the evidence list, the release letter — is here.
