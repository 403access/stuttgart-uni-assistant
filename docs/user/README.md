# User guide

This is the manual for the person holding the phone. It walks the screens of the app in the order a student meets them and says what each one does, what stays on the device, and what is a live read from the university versus the demonstration record.

The app speaks German by default, with an English toggle. Where a button or tab has both names, this guide shows first the German label, then the English one in parentheses: **Heute (Today)**.

## The rule this guide keeps

The app never pretends. Timetable, grades, ILIAS files, and SDG Campus data are the bundled demonstration record of Lena Hartmann. Two things are live reads through the local assistant server: the C@MPUS curriculum structure and course lists of your enrolled studies, and university e-mail. Each screen below says which it is.
