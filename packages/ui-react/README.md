# @ua/ui-react

React DOM components for the operator dashboard and future web surfaces: `AppShell`, `Sidebar`, `Topbar`, `PageHeader`, `Card`, `Section`, `StatCard`, `Badge`, `Avatar`, `Button`, `Field`, `Input`, `Select`, `Checkbox`, `DataTable`, `Pagination`, `Dialog`, `Tabs`, `ToastProvider`, and `ThemeProvider`.

Styles are CSS Modules driven by `@ua/design-tokens`. The package is presentational only: no API calls, routing, or app state. Tests use Vitest and Testing Library.
